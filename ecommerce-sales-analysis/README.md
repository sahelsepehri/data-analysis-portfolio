# E-commerce Sales Performance Analysis

## Project Overview
This project aims to analyze e-commerce sales data and turn it into useful business insights.

## Business Questions
- How do sales and revenue change over time?
- Which products perform best?
- How does order value vary?
- What patterns can help improve business decisions?

## Tools
- Python: Data cleaning and exploratory data analysis
- SQL: Business queries and KPI calculations
- Power BI: Interactive sales dashboard

## Project Status
Initial project structure created. Data collection and analysis are next.
